<h1 align="center">Color Mixer for Craft CMS</h1>

Color Mixer is a Craft CMS plugin that gives Twig the colour operations designers reach for every day. Convert, lighten, darken, mix, tint, shade, fade, and assess colour values without maintaining a separate utility layer.

Take a colour stored in Craft and derive the variants your template needs at render time. A single source value can produce hover states, tints, shades, translucent overlays, or a complementary accent.

## Features

- Convert Hex, HSL, RGB, RGBA, OKLCH, CMYK, and other colour formats without manual parsing in Twig.
- Derive brighter or deeper variants by a controlled amount.
- Blend towards white or black for a related colour scale.
- Combine two values to create a deliberate intermediate colour.
- Adjust opacity and return a value suitable for translucent CSS.
- Choose an appropriate treatment based on the perceived brightness of a colour.
